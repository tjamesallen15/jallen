# Jallen Portfolio

Modern portfolio website showcasing James Allen Tadique's work and skills.

## Projects

### Web React

Modern React portfolio built with TypeScript, Vite, and Tailwind CSS.

**Tech Stack:**

- React 19 + TypeScript
- Vite build tool
- Tailwind CSS + Framer Motion
- Radix UI components

**Quick Start:**

```bash
cd web-react
npm install
npm run dev
```
